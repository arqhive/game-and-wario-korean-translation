# 게임앤와리오 (Wii U) 한글 패치

*Game & Wario* (Wii U, 일본판 `ASAJ`) 비공식 한국어 팬 패치입니다.
일본판(『ゲーム&ワリオ』) 게임에 적용합니다.

**제작: arqhive** · **최신 버전: [v0.9](../../releases/tag/v0.9)**

- 게임 속 대사, 메뉴, 설명문, 게임 카드·샤카퐁 설명을 한글화했습니다.
- 그림 속 글씨(게임 제목 로고, 안내 그림 등)를 한글로 바꿨습니다. 일부 그림은 북미판 그림을 썼습니다.
- 게임 글꼴에 한글(메이플스토리 Bold, 충주김생체, 둘기마요)을 넣었습니다.
- 패처는 가지고 있는 일본판 게임 파일에서 한글판 파일을 만듭니다. 원본 파일은 바뀌지 않습니다.

> 이 저장소에는 **게임 데이터(게임 파일, 추출한 원문 대사, 원본 그래픽, 스크린샷)가 들어 있지 않습니다.**
> 패치를 적용하려면 본인이 소유한 게임에서 직접 덤프한 원본이 필요합니다.

## 사용자용: 패치 적용

### 준비물

- 일본판 「ゲーム&ワリオ」(타이틀 ID `0005000010112D00`)의 복호화된 게임 파일.
  `content\Common\Msg\JP_Japanese` 폴더에 `msbt.warc.fzip`이 있어야 합니다. 북미판(*Game & Wario*)에는 적용할 수 없습니다.
- Windows 10 이상. 따로 설치할 것은 없습니다.
- Wii U 실기: Aroma와 SDCafiine 플러그인, SD 카드. 또는 Cemu.

### 적용 방법

1. [릴리즈 페이지](../../releases/latest)에서 `ASAJ_KPatch_v<버전>.zip`을 받아 압축을 풉니다.
2. 게임 폴더(`content` 폴더가 들어 있는 폴더)를 `패치하기.bat` 위에 끌어다 놓습니다. 그냥 실행하면 경로를 묻습니다.
3. 패처 폴더의 `출력` 폴더에 결과가 생깁니다.
   - Wii U 실기: `출력\sdcafiine` 안의 내용을 SD 카드 `wiiu\sdcafiine\`에 복사하고, SDCafiine을 켠 상태로 게임을 실행합니다.
   - Cemu: `출력\cemu\GameWarioKR` 폴더를 Cemu의 `graphicPacks` 폴더에 넣고, 그래픽팩 설정에서 Game & Wario → Mods → Korean Patch를 켭니다.

### 실행 환경

- **확인함**: Wii U 실기(Aroma SDCafiine), Cemu.

### 알려진 문제

- Wii U 실기에서 타이틀의 「시작」처럼 일부 글자는 본체 글꼴로 나옵니다. 본체 글꼴에 한글이 들어 있어야 보이고, 그렇지 않으면 ??로 보일 수 있습니다.
- 그림 4장은 일본어 그대로입니다.
- 전자 설명서는 번역하지 않았습니다.

## 개발자용

- 도구: [`tools/`](tools)에 분석·추출·글꼴·그림·빌드·검사 도구 소스가 있고, [`patcher/`](patcher)와 [`tools/make_patcher.py`](tools/make_patcher.py)가 배포 패처입니다(Python 3.13, numpy, Pillow, fontTools, scipy).
- 일본어 원문 추출본, 번역 작업 파일, 글꼴 파일, 그림 작업 파일은 게임 데이터이거나 작업용이라 넣지 않았습니다. 그래서 이 저장소만으로는 바로 빌드되지 않고, 원본 게임 파일에서 추출부터 다시 해야 합니다.
